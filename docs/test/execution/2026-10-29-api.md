## 权限分支结论（#120 §3）

- 匿名 2 个（`login`、`refresh`）：正例与非法凭据/令牌分支通过；停用账号登录 209、刷新 209。
- 仅 token 19 个：无 token → 208；停用账号存量 token → 209（B1/A1）。
- 配置 gate 35 个：`user` 无授予 → 205；单页授予账号只开该页，其余配置页仍 205（b-grant）。
- 成员/归属 10 个：申请人/当前处理人/抄送人可读；非成员 `show` 403、附件 205；
  抄送人 `isApprove=false`、附件 `canUpload=false`（D5/E5/E6）。
- 业务校验失败 → 201；已发布模板的 update/remove/再发布 → 201（C5/C6/C8）。

## 已知局限

- 黑盒只覆盖服务端契约，不覆盖 UI 渲染与浏览器行为（归功能/兼容/安全套件）。
- 容器级错误（404/405、multipart 超限）当前被全局 handler 吞成 201，套件只能断言现状；
  修复 #145 后本组需整体改写。
- `sysMenu/doAssign` 的「旧非配置 id 静默跳过」需要历史遗留数据才能构造，
  本轮未执行（干净卷没有 legacy 行），记为未覆盖分支。
- 已发布模板与审批实例会累积；连续多轮后列表分页断言仍成立（用例只按标记查找），
  但全量数据增长需要快照重置控制。
