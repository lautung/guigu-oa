## 未单独成卡、仍值得留意

- `CarbonCopyService` 一个 class 同时是抄送写入、抄送列表读模型（raw SQL + 手拼 `ProcessVo`）和 `ProcessMembershipExtension`；`ProcessController` 直接依赖 concrete class。
- 审批状态 1/2/−1 的标签在 `work-list.ts` 与 `process-instance.ts` 各一份；服务端 `ProcessApprovalSupport`、`ApprovalWriter`、`ApprovalTemplateSupport` 又是另外几套状态词。
- `/info` 仍写死 `roles: "[admin]"`，`perms` 只收 type 2 按钮权限而统一客户端不消费；Redis authority cache 与 DB gate 是两条并存的权限评估路径。

## 实施顺序与验证

按候选 1→8 顺序逐个 grill、实现、验证、提交；每个候选都有独立 ADR 与提交。最终客户端 382 个单测、60 个 e2e，服务端 145 个测试全绿。后续的检查面收口（单测纳入 lint/Prettier、CI 跑 `format:check`、`npm run verify`）见 `AGENTS.md`。
