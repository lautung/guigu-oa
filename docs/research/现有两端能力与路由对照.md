## 7. 对统一客户端规格的摘要

1. **配置面（来自管理端）**：用户、角色、菜单、审批类型、审批模板（含 Activiti 在线设计与发布）、审批实例查询 — 均有完整前后端实现。  
2. **办事面（来自员工 H5）**：发起、三类列表、详情审批、基本信息 — 复用 `/admin/process` 员工向 API；登录改为与管理端相同的用户名密码，不再走微信 OAuth。  
3. **删除项**：微信 OAuth、绑手机、公众号菜单（管理端 UI + `wechat_menu` + WxMp 同步）、模板消息；管理端 `/wechat/*` 整模块。  
4. **不进规格**：部门、岗位、日志（仅模型/菜单占位，无 Controller 与 Vue 页）；H5 `/about`、`/test` 待定；Dashboard 非核心。
