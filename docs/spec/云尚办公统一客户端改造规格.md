# 云尚办公统一客户端改造规格

> **地图**：[云尚办公统一客户端改造规格](https://github.com/lautung/guigu-oa/issues/1)  
> **领域词汇**：仓库根目录 [`GLOSSARY.md`](../../GLOSSARY.md)\
> **现状对照**：[`docs/research/现有两端能力与路由对照.md`](../research/现有两端能力与路由对照.md)

## 1. 目标

将原「PC 管理端 + 公众号员工 H5」收成一个 Web **统一客户端**：

- 用户名密码登录；每个用户**默认可办事**；**配置权限**另授
- 侧栏按权限出**菜单**，不分成两个工作区
- 办事必须能在**手机浏览器**完成；配置按**桌面**使用
- **待处理**列表就是通知
- 配置只收现有已做能力，删除公众号相关能力
- 沿用 **Activiti**，不换引擎

本文档为改造规格（能力 + 信息架构 + 办事/配置关键路径），不含实现细节。

---

## 2. 不在本次规格内

| 项 | 说明 |
|---|---|
| 微信小程序、公众号 | 网页授权、模板消息、自定义菜单、配置里的公众号菜单 |
| 部门、岗位、日志 | 课程未完成模块 |
| 换掉 Activiti / 重做流程设计器 | 沿用现有引擎 |
| Activiti 在线 iframe 设计器 | 主路径为 zip 上传 |
| 站内通知铃铛、邮件等 | 待处理即通知 |
| 旧 H5「关于我们」「测试切账号」 | 静态/开发页 |
| API 路径是否拆 `/admin` | 实现时决策 |
| `openId`、公众号菜单表数据清理 | 实现/迁移时决策 |

## 3. 权限与菜单

### 3.1 配置权限

- **不新增**独立「可配置」布尔字段
- 用户经**角色**被授予 `sys_menu` 中的**配置类菜单**
- **拥有至少一项配置类菜单 ⇒ 有配置权限**
- 授权 UI 沿用「角色 → 勾选菜单树」
- 无配置权限的用户只办事

### 3.2 菜单数据来源

| 分组 | 来源 | 可见性 |
|---|---|---|
| **办事** | 前端内置 | 人人可见，不进菜单管理 CRUD |
| **配置** | `sys_menu` + 角色 | 仅有配置权限时出现 |

侧栏将两类**合并为一棵树**；手机与桌面读同一合并逻辑，仅 viewport 呈现不同。

### 3.3 信息架构（侧栏）

**办事组**（内置）：

1. 发起审批
2. 待处理
3. 已处理
4. 已发起
5. 基本信息

**配置组**（`sys_menu` 动态树，保留现有层级）：

| 分组 | 入口 |
|---|---|
| 组织与权限 | 用户管理、角色管理、菜单管理 |
| 审批设置 | 审批类型、审批模板 |
| 审批查询 | 审批实例列表 |

不含：公众号菜单、Dashboard、部门/岗位/日志。角色菜单授权（assignAuth）为从角色管理进入的隐藏页。

**顶栏**：用户名/头像 + 退出登录；基本信息仅在办事组，不在顶栏重复。

### 3.4 登录落点

登录成功后**一律落到待处理**（手机与桌面相同）。不保留 Dashboard 占位首页。

## 4. 平台与布局

### 4.1 一份应用、按路由分壳

- 一个 Web 应用、一份路由表
- **办事路由**：移动可用壳
- **配置路由**：桌面壳；手机 viewport **硬拦截**（全屏提示「请在电脑浏览器使用」）

### 4.2 手机侧栏呈现

- 办事组：正常展示
- 配置组：侧栏**底部、默认折叠**，附「请在电脑浏览器使用」

### 4.3 手机默认行为

- 登录后落到**待处理**
- 点配置路由：硬拦截，不渲染配置页

## 5. 办事关键路径

> 写法：用户旅程（步骤 → 屏幕职责 → 结果）；正文不写 Vue 路由。

### 5.1 发起

1. 侧栏「**发起审批**」→ 审批中心页（按审批类型折叠展示模板）
2. 点模板 → 动态表单页（按模板定义渲染）
3. 提交 → 发起成功，进入流程

- 不把每个模板单独塞进侧栏
- 仅**已发布**模板在办事端可见

### 5.2 待处理

1. 分页列表（默认登录落地页）
2. 点条目 → 详情页
3. 通过或拒绝 → 跳转**已处理**列表

- 列表/详情展示字段**摘要**（formShowData 语义）；列表可隐藏图片类字段
- 详情：标题、时间、状态、表单字段、竖向**审批流转记录**（操作人 + 描述 + 时间）
- 状态文案：**审批中 / 审批通过 / 审批拒绝**（status 1 / 2 / -1）
- 拒绝：**不要求填原因**；流转记录写「已通过」或「驳回」

### 5.3 已处理

1. 分页列表
2. 点条目 → 详情（只读）

### 5.4 已发起

1. 分页列表
2. 点条目 → 详情（只读）

### 5.5 基本信息

- 侧栏办事组进入
- 仅展示**姓名、手机号**（部门/岗位不进本次规格）

## 6. 配置关键路径

> 写法：用户旅程（步骤 → 屏幕职责 → 结果）；正文不写 Vue 路由。  
> 配置路径仅在桌面 viewport 可用；手机硬拦截。

### 6.1 用户管理

列表 → 增删改 → 启停

### 6.2 角色管理

列表 → 增删改 → **菜单授权**（勾选菜单树，含配置类入口）

### 6.3 菜单管理

树形 CRUD，**仅维护配置类入口**；办事内置项不在此 CRUD

### 6.4 审批类型

列表 → 增删改

### 6.5 审批模板

**新建/编辑（三步向导）**：

1. **基本设置**：审批类型、名称、图标、描述
2. **表单设置**：可视化表单设计器
3. **流程设置**：上传 Activiti 流程 **zip**
4. **提交保存** → 回模板列表

**发布**：

- 列表对**未发布**模板点「发布」→ 办事端可见
- **草稿**（未发布）：可修改、删除、发布
- **已发布**：办事端可选该模板发起

规格只承诺 **zip 上传**主路径；在线 Activiti iframe 设计器不进规格。

### 6.6 审批实例查询

分页列表 → 关键字/状态/时间筛选 → 查看详情（只读）
