# 面试作品化改造规格

> **地图**：[把云尚办公改造成能撑住全栈面试的作品](https://github.com/lautung/guigu-oa/issues/65)
> **领域词汇**：[CONTEXT.md](../../CONTEXT.md)
> **README 叙事草稿**：[docs/prototypes/README-面试作品化草稿.md](../prototypes/README-面试作品化草稿.md)
> **ADR**：[docs/adr/0001-抄送规则不进BPMN且实时可见.md](../adr/0001-抄送规则不进BPMN且实时可见.md)、[docs/adr/0002-附件直传挂审批实例.md](../adr/0002-附件直传挂审批实例.md)

本文把地图上已关闭票的结论收成可执行规格：加什么、改什么、按什么顺序。不含逐文件实现细节；细节由 `ready-for-agent` issue 承担。

---

## 1. 目标

在已完成的「统一客户端 + Boot 4.1 / Flowable 8」底座上，把仓库改造成能撑住**全栈面试**的作品：

- **叙事**：承认尚硅谷《云尚办公》课程起点；主打迁移 + 重构 + 测试固行为；再加原创 **抄送**、**附件直传**。
- **可演示**：`docker compose up` → 静态截图 → 线上 demo（Oracle Always Free + R2）。
- **可深挖**：Flyway、可观测性、审批并发、事务边界、Redis 权限失效五件做透。

受众：全栈岗。无硬期限。红线无（可花钱部署、全量 TS、删旧前端、扩领域）。

## 2. 不在本次规格内

| 项 | 说明 |
|---|---|
| 第三个原创业务模块 | 横切深度由 §6 承担 |
| 字段级可见 / 脱敏、抄送已读、二次抄送、抄送评论 | 见抄送可见性决议 |
| 附件分片续传、哈希秒传、form-create 上传主入口 | 见附件决议 |
| 流程 zip 进对象存储 / 业务附件表 | 仅可配置外部目录 |
| 退出作废全端会话、Redis 会话黑名单取代短 JWT | 与 `CONTEXT.md`「退出」一致 |
| 配置中心、商业 APM、N+1 专项、spotless/checkstyle | 明确不做 |
| 简历正文 / 面试话术稿 | 地图外交付，本规格不写 |
| 自动 CI 部署到 Oracle | 仅 `workflow_dispatch` 可选 |

统一客户端既有能力（登录、办事四列表原语义、配置 CRUD、zip 发布等）仍以既有规格为准；本文只写**增量与覆盖**。

|---|---|

## 4. 安全与鉴权

### 4.1 密码

- `BCryptPasswordEncoder` 替换 MD5。
- 种子 / 测试 SQL **一次性**写入 BCrypt 哈希；文档口令仍可写 `111111`。
- 不做登录时 MD5→BCrypt 自动升级。

### 4.2 Token

- Access **2h** + Refresh **7d**；JWT 密钥外置。
- **退出**只清本机，不作废其他客户端（不改词汇表）。
- **停用**：每次认出查 `status`，失败当未登录。

### 4.3 密钥

- `JWT_SECRET`、DB 口令等走环境变量 / `${…}`。
- `.env.example`；`.env` gitignore。
- **dev** 允许文档化本地默认；**生产 profile 缺省即启动失败**。
- 不做配置中心。

### 4.4 水平鉴权（审批成员）

| 动作 | 谁可以 |
|---|---|
| 读详情 / 流转 / 下附件 | 发起人、当前或历史审批人、该单抄送人 |
| 通过 / 驳回 | **仅**当前审批人 |

附件下载凭证签发必须走同一套校验；配置菜单权限**不能**单独用来换他人附件凭证。

合同测试：规格变了就改测试；增补越权否定用例。

## 5. 原创模块

### 5.1 抄送

详见 ADR 0001 与票 [#66](https://github.com/lautung/guigu-oa/issues/66)、[#76](https://github.com/lautung/guigu-oa/issues/76)、[#78](https://github.com/lautung/guigu-oa/issues/78)。

- 办事组增加 **抄送我的**（顺序见 `CONTEXT.md`：发起 → 待处理 → 已处理 → 已发起 → **抄送我的** → 基本信息）。本轮只按该顺序插入，不做额外视觉重排专题。
- 产生：发起时可设；节点到达时由规则触发。规则存业务表，**不写 BPMN**。
- 挂接：全局 `TASK_CREATED` 监听；`EngineConfigurationConfigurer` 注册；写库与引擎同事务；`isFailOnException=false`；幂等键 `task_id`。
- 可见：整表、完整流转、可下附件；无字段级裁剪。
- 不可：评论、再抄、进待处理、已读状态。
- 实时可见性授权，不快照 `form_values`。

### 5.2 附件直传

详见 ADR 0002 与票 [#77](https://github.com/lautung/guigu-oa/issues/77)、[#78](https://github.com/lautung/guigu-oa/issues/78)。

- 宿主：`oa_process`；发起/补传同一种；元数据表为权威。
- UX：独立附件区；本轮不做 form-create 上传主入口。
- 路径：预签名 → 直传私有桶 → 回调登记；下载临时凭证 **15 分钟**。
- 删除：发起前 pending 可删；**发起后不可删**；结束后保留；pending + TTL 收孤儿。
- 本地 compose：**MinIO**；线上：**Cloudflare R2**。

### 5.3 流程 zip

- 上传落到**可配置外部目录**（非 classpath、非附件桶）。
- 与容器 volume / compose 对齐。

## 6. 深度工程点（做透）

| 点 | 要求 |
|---|---|
| Flyway | 只管 `sys_*` / `oa_*` 及新业务表 + 版本化种子；`ACT_*`/`FLW_*` 仍 `database-schema-update` |
| 可观测性 | Actuator + health；结构化日志；traceId；不上完整 Prometheus/商业 APM |
| 审批并发 | Flowable 任务完成乐观失败 + 业务当前审批人校验；双请求合同测一成一败；无独立分布式锁框架 |
| 事务边界 | 审批写业务表与 Flowable（及抄送监听）同事务/回滚语义写清并验证 |
| Redis 权限 | 角色/菜单变更时**立即删除**对应用户权限 JSON |

## 7. 前端工程化

- **全量 TypeScript**；终点 `strict: true`；迁移期可 `allowJs`，清零后关闭。
- ESLint flat（`eslint-plugin-vue` + `typescript-eslint`）+ Prettier；CI 卡红。
- Playwright **薄冒烟**：登录 → 发起（含附件区）→ 待处理通过/驳回；desktop + mobile viewport。
- `vue-tsc` 进 build/CI；api/store 不许长期 `any`。

---

## 8. CI

- 单 `ci.yml`：`pull_request` + `push` 默认分支。
- Job：`backend`（仅 JDK 21）∥ `frontend`（Node 22）。
- 卡红：`mvn test`；`lint` + `vue-tsc` + `test:unit` + Playwright + `build`；镜像 build（不推仓）。
- 覆盖率可报告，不卡红。
- 不自动部署 Oracle；可选 `workflow_dispatch`。
- README 挂 CI 徽章。
- 不做 spotless/checkstyle。

## 9. 演示可达性

优先级：**一键起 → 静态证据 → 线上 demo**。

### 9.1 Compose

MySQL + Redis + 后端 + 前端 + **MinIO** + Flyway 种子。一条命令。

### 9.2 演示种子

账号：`admin` / `alice` / `bob` / `carol`（BCrypt；口令写 README）。
场景：bob 待处理；已结束一条；carol 抄送非空；至少一条带附件元数据。可写；重置 = DROP + Flyway + 引擎建表 + 场景数据。

### 9.3 线上

Oracle Always Free 单机 compose + R2。不靠 keep-alive 保活；Pay-as-you-go 不强制。托底：compose + 截图。

### 9.4 README

按 [原型草稿](../prototypes/README-面试作品化草稿.md) 替换根 README；补 4 张图（待处理、发起+附件、抄送我的、手机办事）。
