# 审批模板发布冻结，恢复不得猜测原版本

审批模板一旦已发布，其表单与实际审批步骤保持不变，后续上传、发布其他模板或系统恢复都不能改变它。一次发布的部署与模板状态转换必须全部成功；失败撤销本次部署并保持未发布，批量恢复也必须全部成功才生效，失败时撤销本批次新增部署与绑定并停止本次启动，原已发布状态不变。

旧模板仅在有可靠依据确认发布时的执行版本时补齐；无法确认时保留已发布状态，但拒绝该模板的发起与恢复并明确报错。接受人工修复与整批重试的成本，避免猜用最新版本或同名流程 zip 悄然改变已发布审批步骤；不静默跳过有问题的模板，也不把它改回未发布。

无法确认原有内容的旧模板在配置中仍显示已发布，并说明“暂不可发起，需核实原审批内容”，继续保持只读。发起审批清单只列可用模板，空时显示“暂无可发起的审批模板”；通过旧地址或直接提交访问时明确拒绝并说明原因。

**2026-11-06 修订（#271）**：发布产物不再等于上传的流程 zip——模板设置里的审批人规则随发布冻结，发布产物是流程 zip 与规则 sidecar 的合成件，发布证据覆盖合成件；已发布内容固定、恢复不得猜测的语义不变。见 ADR 0069。
