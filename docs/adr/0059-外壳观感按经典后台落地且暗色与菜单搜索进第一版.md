# 外壳观感按经典后台落地，暗色与菜单搜索进第一版

#209 用三个结构不同的外壳原型把「顶部一级 + 左侧二级 + 多标签 + 工作台」已定形态下的观感翻了一遍：A 经典后台、B 收件箱优先、C 紧凑指挥台。用户选定 **A 经典后台整包落地**，不采用 B/C，也不做「A 的壳 + B 的工作台 + C 的列表」的混搭。原型在一次性分支 `prototype/tabbed-shell-209` 的 `client/guigu-oa-client/prototype/shell/`，只作证据，不合并、不提 PR。

决定：

- **底座**：A 经典后台。后续实现票按本 ADR 的尺寸与层级做，不再在实现里重选外壳。
- **标签页**：38px 标签条 + 32px 卡片式标签（上圆角 6px、激活项内嵌 2px 主色上边线、标题最大 170px 省略号）。工作台固定不可关，带固定图标。关闭菜单收在标签条右侧下拉：关闭当前/其他/全部；中键关闭单个标签作为补充。标签横向溢出滚动，滚动条隐藏。面包屑单独一行放在标签条下（`首页 / 一级 / 二级 / 页面`），不塞进标签。标签仍只存路径与标题，不做 keep-alive（ADR 0051）。
- **混合导航**：顶部一级保持图标 + 文字的五项（工作台/办事/系统管理/系统监控/系统工具），激活项用主色浅底药丸。左侧 220px 深色树（`#1f2733`），模块内平铺项 + 嵌套分组标题（日志管理/审批设置/审批管理），激活项主色实底；折叠为 62px 图标栏，折叠按钮固定在侧栏底部（顶部不重复）。窄屏（< 900px）标签条隐藏，侧栏改为左侧抽屉 + 遮罩，抽屉宽 240px。
- **工作台**：页头（标题 + 日期 + 当天到期数 + 发起审批/处理待办）→ 四张 KPI 卡（待处理主色强调、今日已办、我发起的、抄送我的）→ 两列：近期审批紧凑表（标题/类型/发起人/状态/提交时间）+ 右栏公告（未读点）与 2×2 快捷入口。加载态用 8 行骨架，空态用 `el-empty` + 发起审批 CTA。首屏不放大表格、不做图表。
- **列表页**：页头（标题 + 总数 + 导出）→ 常驻内联查询表单（关键词/审批类型/状态/发起时间范围 + 查询/重置）→ 动作行（总数与已选、导出、列设置弹层）→ 边框斑马纹表格（多选、状态 tag、行内查看/催办、操作列固定右）→ 右侧分页（总数/页大小/页码）。密度按 Element Plus small：表头与行约 34px、卡片间距 10–12px、内容区 16px。列设置是弹层复选，不占表格空间。窄屏查询表单转单列，表格内部横向滚动，分页换行。
- **主题与尺寸**：亮/暗两套都进第一版；暗色走 `html.dark` + Element Plus `dark/css-vars.css`，自定义表面只用 `--el-bg-color*`/`--el-text-color*`/`--el-border-color*`，不写死颜色。主色以 `--el-color-primary` 为唯一来源，派生 light-3/5/7/8/9 与 dark-2；第一版固定 Element Plus 默认蓝，不做用户换色。全局尺寸保留紧凑/默认/宽松三档，默认紧凑，由 `ElConfigProvider` 统一下发；页面不各自改尺寸。
- **顶栏件**：面包屑、侧栏折叠、全屏、公告铃铛、用户菜单、菜单搜索都进第一版。菜单搜索是顶栏图标 + 弹层，按标题与面包屑做包含匹配，回车打开第一条；菜单量在百条以内不引 fuse 依赖，后续需要模糊打分再加。公告铃铛位置进第一版，未读数按公告票（ADR 0055）P1 接入。
- **不进第一版**：标签右键菜单（下拉已覆盖）、标签持久化、keep-alive、工作台以外的自定义固定标签、主色选择器、用户自定义密度。

考虑过的替代方案：

- **B 收件箱优先**：工作台首屏更聚焦，但上下文侧栏与 Chrome 式标签把后台做得太像邮件客户端；用户选 A。
- **C 紧凑指挥台**：列表密度最高，但全宽下划线标签与窄侧栏牺牲了一级导航的可见性；用户选 A。
- **A 的壳 + B 的工作台 + C 的列表**：三套密度混用会让同一间距在不同页漂移；用户明确选 A 整包。
- **只做亮色**：暗色是 CSS 变量层的低成本能力，晚做要回头补自定义颜色；第一版一起做。
- **不做菜单搜索**：后台菜单会很快过 40 页，顶栏搜索是后台的常用入口；先做轻量匹配，不引依赖。

后果：

- 外壳实现票按上述尺寸与层级落地；工作台与列表页实现票直接复用这套密度，不再各写间距。
- 自定义组件一律用 Element Plus 变量，暗色与三档尺寸不需要第二套样式。
- 标签不缓存，列表页激活重读继续遵循 ADR 0009/0018；不要因为「标签像浏览器」而加 keep-alive。
- 900px 是外壳断点；窄屏只保证「能用」，重交互页仍桌面优先（ADR 0051）。
