# 撤销注册页与 i18n 的不做裁决，Druid 控制台由数据监控扩展替代

#208 的蓝图 §1 曾把「注册页、在线代码生成器、i18n、多数据源、Druid 控制台」逐条列为明确不做。2026-11-04 用户对照若依 Vue3 后要求补齐后台基座，五项逐条重裁。侦察到四件与票面假设不一致的事实：

- **若依 Vue3 本身没有 i18n**：`package.json` 无 `vue-i18n` 或任何国际化依赖。所以「补 i18n」不是对齐若依，是给本产品新增能力；蓝图当初「无驱动」的判断仍然成立，改的是取舍而不是事实。
- **Druid 控制台与我们的栈冲突**：全栈 Hikari（`application-dev.yml:18`），若依的「数据监控」是 iframe 到 `/druid` 控制台。引 Druid 只为那个只读面板，却要连带一套连接池实现与登录、session、IP 白名单三件安全事。
- **登录日志没有事件类型列**：`SysLoginLog` 只有 `status`（0 成功/1 失败/2 锁定/3 解锁）。注册要进审计，必须加 `event` 列，否则只能挤进 `status` 或 `msg`。
- **缓存前缀已有先例**：权限缓存键是 `perm:cache:`，缓存列表按四前缀白名单浏览与清理（ADR 0060）。字典与参数的缓存键必须进同一白名单，否则页面上看不到也清不了。

决定：

- **撤销「不做注册页」**：注册页进 P1。默认关闭，由参数 `sys.account.registerUser` 打开；新注册用户零后台角色，登录后只进工作台与办事，后台权限必须管理员授予；注册成功后跳登录页并预填用户名，**不自动登录**；按 IP 限流（Redis 计数，5 次/分钟），不计入账号锁定；审计给 `sys_login_log` 加 `event` 列（`login` / `register`），`status` 复用，登录日志页面筛选加「注册」一项。密码策略沿用现有 min 6，不做验证码。
- **撤销「不做 i18n」**：i18n 进 P2，先做框架（`vue-i18n` + Element Plus locale 同步）。本波只抽外壳（导航/标签/顶栏/用户菜单）、登录页、通用组件、request 层错误文案、个人中心与锁屏；业务页面文案后续逐页抽，不阻塞。DB 业务名（菜单/角色/审批类型/模板）与服务端 `Result` 消息**不翻**。顶栏语言下拉存 localStorage，默认 `zh-CN`。
- **Druid 控制台不引入**：数据监控页扩「SQL 统计 + 连接池历史」，数据来自 Hikari 自带 metrics 与既有慢 SQL 内存环；不新增连接池实现、不新增 Web 安全面。「不引 Druid」维持。
- **代码生成维持不做**：在线生成器与手写 module/ADR/ArchUnit/合同测试约定冲突；若将来要省脚手架，另起「离线脚手架」票，不在本轮。
- **多数据源维持不做**：单库是审批永久副本与回滚补偿的事务前提（ADR 0012）；没有第二个库的真实驱动，读写分离也只为不存在的主从而加一层路由。
- **通用表单构建维持 ADR 0061**：由「审批设置 → 模板设置」承载，不设独立页。

考虑过的替代方案：

- **在线代码生成器**（否决）：模板要跟着本仓约定持续维护，生成物还要人改；离线脚本可版本化、可 CI 编译验证，但那是独立一票。
- **业务分库 / 读写分离**（否决）：前者跨库事务推翻 ADR 0012 的补偿设计；后者在单实例单库部署下只增加路由层与一致性风险。
- **Druid 控制台**（否决）：为一个只读面板新引连接池与三件安全事，收益不匹配；现有数据监控页已覆盖连接池与慢 SQL。
- **i18n 全栈**（否决）：DB 业务名要加 i18n key 列并改菜单管理，服务端消息与校验文案要全部改造，收益与成本不成比例。
- **注册后自动登录**（否决）：绕过登录日志与失败计数，审计面出现暗区。
- **注册与登录共用 `status` 语义**（否决）：注册既不是成功登录也不是失败登录，挤进 `status` 会让「登录日志」这个页面名撒谎。

后果：

- 蓝图 §1、§2、§9、§11、§12 同步改写；#206 的地图正文更新 Out of scope 与 Decisions so far，并挂本批 13 票。
- 新增两个薄模块 `lautung-oa-dict`、`lautung-oa-config`；ArchUnit 依赖边增加 `config ← auth`（注册开关由 auth 读 config 端口），字典暂无服务端下游。
- `sys_login_log` 加 `event` 列（默认 `login`），登录日志页面筛选、审计合同与安全套件随之扩展。
- 字典/参数缓存键使用 `dict:` / `config:` 前缀并进缓存列表白名单；清理动作仍只允许 `perm:` 前缀（ADR 0060 的边界不放宽）。
- 注册是新的匿名端点，个人中心头像上传是新的 multipart 面，两者必须进安全套件；每波末跑五类测试轮。
- i18n 的否决理由从「无驱动」改为「框架先行、按需抽页」：若长期无人切到 English，框架保留但不继续抽业务页文案；不假装有双语需求。
