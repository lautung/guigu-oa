# 配置权限以菜单树为授予权威，产品目录只兜底分类

配置权限继续以当前用户被授予的配置类菜单为唯一授予权威；侧栏、菜单组、占用和返回入口都由同一份授予解释得出。用户未被授予某页时菜单树里可能没有该节点，因此保留一份显式的产品配置页目录，仅用于已知配置页的分类和隐藏页父级兜底；不采路由 meta，也不把路径前缀当权威。实现上收成一个纯函数 seam（`configPermission(menus)`），不引入 access-policy 领域对象，也不按用户缓存授予。合并后的实现里，`entryOf` 在隐藏页位于菜单树时取最近的可见菜单父级，而两个已知隐藏页的占用判断仍用目录父级映射以保住既有授予；自定义隐藏页见 #104。
