# 配置权限以菜单树为授予权威，产品目录只兜底分类

配置权限继续以当前用户被授予的配置类菜单为唯一授予权威；侧栏、菜单组、占用和返回入口都由同一份授予解释得出。用户未被授予某页时菜单树里可能没有该节点，因此保留一份显式的产品配置页目录，仅用于已知配置页的分类和隐藏页父级兜底；不采路由 meta，也不把路径前缀当权威。实现上收成一个纯函数 seam（`configPermission(menus)`），不引入 access-policy 领域对象，也不按用户缓存授予。隐藏页的入口父级和占用父级使用同一份解析：隐藏页在当前菜单树里时取菜单树里最近的可见父级，只有当前菜单树里没有的已知隐藏页才用目录里的父级映射兜底；`entryOf` 和 `canOccupy` 都从这一份解析得出。因此自定义隐藏页跟随其可见父级的授予，不需要目录条目；菜单授权和审批模板设置在菜单树里缺少该页时仍沿用目录父级，保住既有授予。
