# 退出按登录凭证作废，其他客户端仍能认出这个用户

#134 复现出一个 S3：`POST /admin/system/index/logout` 只 `return Result.ok()`，`TokenAuthenticationFilter` 只验签不查吊销，于是退出后 access token 在 2 小时内继续可用，refresh token 7 天内还能换新令牌。GLOSSARY 的「退出」同时写着「不作废会话，其他仍留着进入结果的客户端仍能认出这个用户」，所以修复不能做成用户级踢出：那会把同一账号在其他设备上的进入结果一起作废，与本条目和「停用不是踢出会话」都冲突。

现在一次登录签发的一对 access/refresh 令牌共享一个 `sessionId`（`JwtHelper.createTokenPair` 生成，两个令牌都带这个 claim）。退出时 `IndexController.logout()` 只作废当前请求里能解析出的凭证的 `sessionId`：`TokenRevocation.revoke(sessionId)` 在 Redis 写 `token:revoked:<sessionId>`，TTL 取 refresh 令牌的 7 天寿命——这是同一进入结果里最长寿的令牌，marks 不需要永久保留。`TokenAuthenticationFilter` 解析 access 令牌后先查这个标记，命中就按认证失败返回 `body.code=208`；`IndexController.refresh()` 同样查 refresh 令牌的标记。被作废的只是这一对凭证，同一账号的另一次登录有自己的 `sessionId`，它的 access/refresh 都继续有效。

`logout` 因此不能要求 access 令牌仍然有效：空闲超过 2 小时的客户端点退出时 access 已过期，认证过滤器会把它挡在 208，控制器根本到不了，而 7 天有效的 refresh 令牌还能换新令牌——这正是要堵的洞。所以 `logout` 放进匿名路径，客户端同时交上 `token` 头和 `refreshToken` 请求体，控制器对两者分别解析，能解析出的 `sessionId` 都作废；两者都过期时无事可做，仍返回 `code=200`。匿名不扩大攻击面：调用者只能作废自己手里已有的凭证。

`refresh` 续签的 access 令牌必须沿用 refresh 令牌的 `sessionId`（`createAccessToken(userId, username, sessionId)`），否则「先续签、后退出」时新的 access 令牌会被漏掉；这对 7 天有效期的 refresh 令牌尤其重要。`JwtHelper` 的读取收成 `readAccessToken` / `readRefreshToken` 两个入口，一次解析返回 `TokenClaims(userId, username, sessionId, expiresAt)`；原来分三次解析的 `getUserId` / `getUsername` / `getRefreshUserId` / `getRefreshUsername` 删除，过滤器、`/info` 与 refresh 改读 claims。

没有 `sessionId` 的令牌按无效处理：它们是这次修改之前签发的，无法被任何退出作废。部署后现存会话需要重新登录一次，这是一次性的代价，也是「每个能通过鉴权的令牌都可被退出作废」这条不变量的前提。

否决的替代方案：用户级会话版本号——实现更短，但退出会作废全端，违背 GLOSSARY 的「退出」并把其他设备踢下线；access/refresh 各带一个 `jti` 黑名单——退出请求只带 access 令牌，拿不到 refresh 的 `jti`，要客户端额外上报 refresh token，服务端还得分别校验两套键；把 refresh 改成一经使用即轮换并作废旧值——只解决续签链，不解决退出后的 access 重放。

代价：鉴权路径多一次 Redis 读取（权限缓存本来就在 Redis，故障面不变），Redis 不可用时鉴权失败；客户端「退出」从纯本地清理变成先请求服务端再清理，服务端吊销失败时仍以本地离开为准；`logout` 从受保护路径变成匿名路径；GLOSSARY 的「退出」要补一句「这台客户端手里的凭证同时作废」。服务端测试新增 4 条 HTTP 合同（退出作废 access+refresh、只作废本次登录、续签后仍随本次退出作废、access 已过期仍凭 refresh 作废）与 `JwtHelper`、`RedisTokenRevocation`、过滤器的单元用例；客户端 `user` store 新增「服务端吊销失败也清本地凭证」用例。
