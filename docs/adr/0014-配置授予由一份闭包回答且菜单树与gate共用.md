# 配置授予由一份闭包回答，菜单树与路由 gate 共用

`hasMenuAccess` 在 DB 里沿父链判定，`findUserMenuListByUserId` 只返回 `sys_role_menu` 里的行，`MenuHelper.buildTree` 只以 `parent_id = 0` 为根；角色只被授予叶子 `sysUser` 时，路由 gate 放行，`/info` 却返回空树，客户端 `configPermission` 因此判成没有配置权限并重定向。同一套分类还散在 `doAssign`、菜单管理、授权树和客户端 `isConfigClassMenu` / `KNOWN_CONFIG_PAGES` 里；`saveMenu` 只拦受保护路径，非配置菜单能不能建只由客户端把守。

现在把「哪些配置菜单被授予」收成 `auth/grant/ConfigurationGrant`：`snapshot(userId)` 返回 `GrantedConfiguration`，interface 只有 `hasAnyPage()`、`covers(menuPath)`、`entries()`；`isConfigurationMenu(menu)` 供写侧使用。snapshot 一次全量读菜单表，在内存里建父链；`sys_role_menu` 只存实际授予，读取时补祖先，`covers` 只认精确授予的页面，祖先不自动获得页面权限。只授目录不算配置权限；隐藏页跟可见父级同一条授予：父级页面被授予即有效，单独授予隐藏页而父级未授予时无效、不扩权。

`/info` 改为扁平 `configMenus`：`[{ path, parentPath, title, type, hidden, sort }]`，绝对路径，只含被授予页面及其祖先，隐藏页随可见父级一起发；`RouterVo`、`MetaVo`、`buildRouter` 删除，`findUserMenuListByUserId` 与 `hasMenuAccess` 从 `SysMenuService` 移除。gate 继续使用 `sys_menu.path` 短路径，35 个注解不改；`ConfigurationMenuGate` 直接依赖 `ConfigurationGrant`。客户端组归属改由路由表的 `meta.menuGroup` 与 `meta.hiddenParentPath` 声明，`KNOWN_CONFIG_PAGES` 删除，`config-permission` 只消费 server entries 加路由表，仍拥有侧栏、占用与 `hasConfigPermission` 的客户端投影。

写侧也收进同一个分类：`/toAssign`、`findNodes`、`saveMenu`、`updateMenu` 都按 `isConfigurationMenu` 过滤与校验，菜单管理只维护目录与页面，表单删除按钮（type 2）与「权限字符」；`doAssign` 保留「已存在的非配置 id 静默跳过」的迁移分支，使仍带旧授予的角色还能完成一次重新授权。

否决的替代方案：写入时补祖先会改变 `sys_role_menu` 语义并要求回填，读时补更诚实；保留 `KNOWN_CONFIG_PAGES` 会让同一事实继续有两份声明，ADR 0007 选目录是因为当时服务端不输出闭包，现在服务端给出绝对路径与父路径，目录只剩下路由知识；只收读侧会把分类重复从侧栏搬到菜单表单，并让「只能维护配置菜单」继续只在客户端成立；把隐藏页授予视为授予父级会让一个隐藏页顺带拿到父页全部读写；把 gate 注解改成绝对路径等于重写解析规则；让 `configMenus` 与 `routers` 并存会留下两份可再次分叉的菜单事实。

代价：`/info` 是硬切换，只有统一客户端消费且 CI 只构建它；snapshot 每次全量读菜单表，表很小，不新增缓存；菜单管理不再显示历史非配置菜单（行保留在库里）；ADR 0007 的「不采路由 meta、保留产品目录」被本 ADR 取代，其「菜单树是授予权威」的结论不变。测试面：新增 `ConfigurationGrantTest` 覆盖叶子单独授予、只授目录、隐藏页父级、非配置菜单与无角色；`ConfigurationRouteAuthorizationContractTest` 增加叶子单独授予用户 `/info` 的 `configMenus` 断言；客户端 `config-permission.spec.js` 改为消费 entries 加路由表，`config-page-catalog.spec.js` 换成路由 `meta.menuGroup` 的结构断言，recognition/store/e2e fixtures 从 `routers` 改为 `configMenus`。

Related: ADR 0007（授予权威保留，实现选择被取代）；ADR 0013（gate 注解、种子角色与隐藏页父级语义不变）；ADR 0009（列表读取不变）。
