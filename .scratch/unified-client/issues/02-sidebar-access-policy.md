## Parent

Part of #8（实现：云尚办公统一客户端）

## What to build

**混合侧栏**与**访问策略**完整落地：办事五项（发起审批、待处理、已处理、已发起、基本信息）前端内置、人人可见；配置项来自角色过滤后的 `sys_menu`，仅有**配置权限**时出现；两组合并为一棵树（不是工作区 Tab）。

按路由分壳：办事路由用移动可用 layout；配置路由用桌面 layout。手机 viewport 访问任意配置路由时全屏硬拦截「请在电脑浏览器使用」；手机侧配置组在侧栏底部默认折叠并附相同提示。

导航与访问策略模块（规格单一测试接缝）完整单测：侧栏合并、配置权限推导、路由分类、viewport 策略、默认落点。

## Acceptance criteria

- [ ] 办事五项始终出现在侧栏，顺序正确，不进菜单管理 CRUD
- [ ] 无配置权限用户看不到配置组
- [ ] 有配置权限用户看到办事 + 配置合并树
- [ ] 办事页在移动壳可渲染；配置页在桌面壳可渲染
- [ ] 手机访问配置路由 → 全屏拦截，不渲染配置页
- [ ] 手机侧配置组底部折叠 + 「请在电脑浏览器使用」
- [ ] 导航与访问策略模块单测全部通过
