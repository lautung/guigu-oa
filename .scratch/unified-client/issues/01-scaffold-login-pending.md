## Parent

Part of #8（实现：云尚办公统一客户端）

## What to build

用户打开新的**统一客户端**，用用户名密码登录，登出后会话清除；登录成功后一律进入**待处理**（不是 Dashboard）。顶栏显示用户名/头像与退出。待处理页展示分页列表并接通现有 API（空列表也算验收通过）。未登录或会话过期时跳转登录页，支持登录后回到原目标路由。

本票同时落地导航模块雏形：默认登录落点、基础路由守卫，以及对应单测。

## Acceptance criteria

- [ ] 存在可启动的统一客户端 Vue 应用（替代双前端的起点）
- [ ] 用户名密码登录、登出可用，复用现有 `/admin/system/index/login`、`/info`、`/logout`
- [ ] 登录成功后桌面与手机均落到**待处理**
- [ ] 待处理分页列表接通 `findPending` API
- [ ] 顶栏显示用户名/头像与退出；无重复导航
- [ ] 未登录访问受保护路由 → 登录页；过期 token → 重新登录
- [ ] 导航模块单测覆盖：默认落点为待处理、未登录拦截

## Blocked by

None — can start immediately.
